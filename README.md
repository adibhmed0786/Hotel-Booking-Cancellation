# Hotel Booking Cancellation Analysis

Analysis of hotel booking cancellations using the Hotel Booking Demand dataset and Excel.

## Contents

- `Data Analysis Using Excel.xlsx` - local Excel analysis workbook (not included in the public repository).
- `hotel_booking.csv` - local source dataset (not included in the public repository).

The source files are intentionally excluded from this repository because they contain personal-information fields such as names, email addresses, phone numbers, and credit-card fragments. Use a properly anonymized or publicly licensed copy of the dataset for analysis.

## Dataset overview

The dataset describes hotel reservations and includes fields related to:

- Hotel type and arrival dates
- Length of stay and lead time
- Guest counts
- Meal, market segment, and distribution channel
- Deposit and customer type
- Room assignment and special requests
- Reservation status and cancellation indicator

## Analysis goals

- Understand the factors associated with booking cancellations.
- Compare cancellation patterns between resort and city hotels.
- Explore the relationship between lead time, deposit type, customer type, and cancellation behavior.
- Support data-driven hotel booking decisions.

## Getting started

1. Obtain a public, anonymized, and appropriately licensed version of the dataset.
2. Place the dataset and workbook in the project directory.
3. Open `Data Analysis Using Excel.xlsx` in Microsoft Excel or another compatible spreadsheet application.
